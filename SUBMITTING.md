# Before you submit

You get one submission per team, and you can't edit it after you send it. Check everything below first.

- [ ] The repository is public, and the README has "do X, see Y" steps an AI judge can follow
- [ ] Your demo post is live on X, says you built it at NEAR HACKATHON, and has a video or screenshots attached
- [ ] You have a mainnet NEAR account for the prize payout, either your own or the team's
- [ ] You've selected every track your project fits
- [ ] There are no keys or secrets anywhere in the repo history
- [ ] You're submitting before Nov 14, 2026, 23:59 UTC

Submit through the [form](https://nearhackathon.com/#apply), or let your agent use the submission API described in [HACKATHON.md](https://nearhackathon.com/HACKATHON.md). The agent must show you the full payload and wait for your OK before it sends anything.
