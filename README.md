# NEAR Hackathon Starter Prompts

Copy-paste prompts for every build track in the [NEAR Hackathon](https://nearhackathon.com/), one file per track. Each prompt gives your coding agent a real, two-week scope, the docs to read first, and a checkpoint where it stops and waits for you.

## How to use these

1. Paste [`00-setup.md`](00-setup.md) into your coding agent once. It has the agent read HACKATHON.md and install NEAR's agent skills.
2. If your track mentions the Agent API, also paste [`agent-api.md`](agent-api.md).
3. Open your track's file, paste the prompt, and edit the parts in `[brackets]` to fit your idea.
4. Swap the starter idea for your own if you have a better one. Keep the requirements and the checkpoint.
5. Before you submit, go through [`SUBMITTING.md`](SUBMITTING.md).

## Key dates

| Event | Date (UTC) |
| --- | --- |
| Hackathon starts | Nov 1, 2026, 00:00 |
| Development ends and submissions close | Nov 14, 2026, 23:59 |
| Judging | Nov 16 to 18, 2026 |

Every track pays $10K, $3K and $2K to its top three, and one project wins a $55K grand prize. All prizes are paid in NEAR.

The jury includes Claude Code and Codex as AI judges, so write your README for a machine reader as well as a human one. The organizers ask for "do X, see Y" steps a judge can follow.
